## Grupo 9: Estructuras de datos probabilísticas

- **Concepto de estructuras de datos probabilísticas:** Definición de las estructuras que utilizan decisiones aleatorias o aceptan cierta incertidumbre para mejorar el rendimiento o reducir el consumo de memoria.
- **Filtros de Bloom:** Explicación de la estructura basada en bits utilizada para comprobar si un elemento podría pertenecer a un conjunto.
- **Funciones hash en filtros de Bloom:** Análisis de cómo varias funciones hash determinan las posiciones que se modifican durante la inserción y la consulta.
- **Falsos positivos:** Explicación de por qué un filtro de Bloom puede indicar la posible presencia de un elemento que no se insertó.
- **Listas de saltos (`skip lists`):** Explicación de la organización de elementos ordenados mediante múltiples niveles de enlaces.
- **Búsqueda, inserción y eliminación en skip lists:** Análisis de las operaciones y del papel que desempeñan los niveles superiores.
- **Comparación entre estructuras probabilísticas y deterministas:** Análisis de las diferencias en memoria, rendimiento y garantías de exactitud.
- **Aplicaciones:** Presentación de usos en bases de datos, cachés y sistemas distribuidos.
